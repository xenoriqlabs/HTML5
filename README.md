# HTML5 — Learning & Practice

Welcome to my **HTML5 Learning & Practice Repository**.

This repository represents my step-by-step journey of learning HTML5, starting from the fundamentals and progressing toward modern HTML concepts, forms, tables, multimedia, accessibility, SEO, semantic HTML, iframes, images, and practical exercises.

## About This Repository

The purpose of this repository is to build a strong and practical understanding of **HTML5** through structured learning, hands-on coding, exercises, and experimentation.

Each topic is practiced through individual HTML files, while related concepts are organized into dedicated folders for better structure and navigation.
